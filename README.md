# 📝 Task Manager App

A full-stack Task Management Web Application built using React, Node.js, Express, and MySQL.

---

## 🚀 Features
- Add Tasks
- Edit Tasks
- Delete Tasks
- View Tasks
- Task Status (Pending / In Progress / Completed)

---

## 🛠️ Tech Stack
Frontend: React.js  
Backend: Node.js, Express.js  
Database: MySQL
